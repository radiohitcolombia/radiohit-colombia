# Radio Hit Colombia

Sitio oficial preparado para GitHub Pages y Decap CMS.

## Publicación

1. Subir todos los archivos a la rama `main`.
2. En GitHub: Settings > Pages > Source > GitHub Actions.
3. Esperar a que termine la acción "Publicar sitio en GitHub Pages".

## Panel

El panel estará en `/admin/` después de publicar el sitio.

> Importante: Decap CMS necesita configurar autenticación OAuth para poder guardar cambios en GitHub. La estructura del panel ya está incluida; la autenticación se configura en la siguiente fase.
